# Copywriting Frameworks Reference

Quick-reference cheat sheets for the four core frameworks used in Module 1.

---

## AIDA (Attention → Interest → Desire → Action)

| Stage | Goal | Techniques | Example (AI Scriptwriting Tool) |
|-------|------|------------|----------------------------------|
| **Attention** | Stop the scroll | Hook, pattern interrupt, bold claim, visual anomaly | "Your video script is costing you 80% retention." |
| **Interest** | Keep them watching | Relevance, specificity, story, data point | "We analyzed 10,000 viral Reels. The top 1% share one structural trait." |
| **Desire** | Make them want it | Benefit visualization, social proof, future pacing | "Imagine every script you write hitting that trait automatically." |
| **Action** | Tell them what to do | Low-friction CTA, urgency, clear next step | "Tap the link to generate your first optimized script free." |

**Best for:** Instagram Reels, TikTok, YouTube Shorts (high retention focus)

---

## PAS (Problem → Agitation → Solution)

| Stage | Goal | Techniques | Example |
|-------|------|------------|---------|
| **Problem** | Name the pain | Specific, relatable, quantified | "You spend 3 hours writing a script that gets 200 views." |
| **Agitation** | Twist the knife | Consequences, emotional cost, identity threat | "That's 3 hours you'll never get back — and the algorithm just buried you deeper." |
| **Solution** | Present the way out | Your method, proof, ease of adoption | "This AI agent turns raw notes into viral scripts in 90 seconds. Here's the output." |

**Best for:** LinkedIn (professional pain points), Twitter threads, educational content

---

## Hook-Value-CTA (HVC) — Short-Form Optimized

| Component | Max Length | Function | Example |
|-----------|------------|----------|---------|
| **Hook** | 0-3 sec / 1 line | Pattern interrupt + promise | "Stop writing hooks. Steal this framework instead." |
| **Value** | 3-30 sec / 3-5 beats | Dense, actionable insight | "1. Curiosity gap. 2. Contrarian truth. 3. Pain point. 4. Social proof. 5. Bold claim." |
| **CTA** | Last 3 sec / 1 line | Frictionless engagement | "Save this. Try #3 tomorrow. Report back." |

**Best for:** TikTok, Reels, Shorts (under 60 sec), X/Twitter single tweets

---

## StoryBrand (SB7) — Narrative Clarity

| Element | Question | Application |
|---------|----------|-------------|
| **Character** | Who is the hero? | The creator / marketer |
| **Problem** | What villain do they face? | Algorithm opacity, time poverty, creative block |
| **Guide** | Who helps? | Your agent / framework / methodology |
| **Plan** | What's the 3-step path? | 1. Input raw notes. 2. Get structured script. 3. Post & measure. |
| **Call to Action** | What do they do now? | "Generate your first script" |
| **Success** | What does win look like? | Consistent 10k+ views, 50% time saved |
| **Failure** | What if they don't act? | Stuck at 200 views, burnout, invisible brand |

**Best for:** LinkedIn long-form, YouTube descriptions, landing page copy, email sequences

---

## Framework Selection Matrix

| Platform / Goal | Primary Framework | Secondary | Why |
|-----------------|-------------------|-----------|-----|
| Reels/TikTok/Shorts (retention) | HVC | AIDA | Hook-first, dense value, fast CTA |
| LinkedIn (authority) | PAS → SB7 | AIDA | Professional pain → narrative resolution |
| Twitter/X Thread (virality) | HVC (per tweet) | PAS | Each tweet = mini HVC; thread = PAS arc |
| YouTube (SEO + watch time) | AIDA → SB7 | HVC (intro) | Long-form needs sustained interest + narrative |
| Email/Newsletter | SB7 | PAS | Relationship-building over time |

---

## Implementation Notes for Module 1

1. **Auto-select** framework per platform using the matrix above
2. **Blend** when beneficial: e.g., YouTube intro = HVC hook → AIDA body → SB7 description
3. **Tone overlay**: Apply `tone_of_voice` constraints AFTER framework structure (forbidden words, emoji density, line breaks)
4. **Hook variety**: Module 1 Step 3 generates 5 hooks × 5 types = 25 hook candidates; framework selection picks the best match per platform
